# **RealOS 3.0.5.0**

an operating system simulator heavily inspired by @sungsamtech's OriginWEB (https://quandz24-ui.github.io/OriginWEB)

***The website may have different results of performance and visuals depending on your choice of browser and how fast the device is**

PC Controls
Space key = Exit app

Q = Power off the phone

E = Open control center

older version of RealOS can be found here: https://github.com/RealOmarRblx/RealOS-v2
